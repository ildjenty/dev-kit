`devkit/SKILL.md` defines the procedure for starting, advancing, submitting, pausing, and resuming work, presenting questions, and launching assigned judges and planners. It uses Markdown with `name` and `description` in YAML front matter.

`devkit init` installs the canonical skill in `.agents/skills/devkit/` and links `.claude/skills/devkit` to it. Host settings are merged into `.claude/settings.json`, `.codex/hooks.json`, `.codex/config.toml`, and `.codex/rules/`; subagent definitions are installed in `.claude/agents/` and `.codex/agents/`. Norms belong to the repository, and output schemas are supplied by the binary in briefs. Follow the commands and returned instructions described in the skill; there is no separate operations playbook.
