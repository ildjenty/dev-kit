# harness

- Checks: Principles and contracts: Follow the principles in `principles/harness.md` and the applicable schemas and runtime rules in `schemas/`, `stages/README.md`, `checks/README.md`, and `plans/README.md`. Required checks: Follow principle 5 for selecting mechanisms and the detection test requirements (`checks/README.md#detection-tests`, tests of whether aspect files produce the expected judgments) for making an aspect handled by a judge (`schemas/plan.json`, the role responsible for a check) required. Skill: Check for a `description` (`https://agentskills.io/specification#description-field`, the skill description field), placement (the canonical devkit skill is `.agents/skills/devkit/`, linked from `.claude/skills/devkit`), and references. Follow principle 5 of `principles/working.md` (`principles/working.md#5-%E5%AE%9A%E5%9E%8B%E5%87%A6%E7%90%86%E3%81%AF%E3%82%B3%E3%83%9E%E3%83%B3%E3%83%89%E3%81%AB%E3%81%97%E6%89%8B%E9%A0%86%E3%81%AF%E3%81%9D%E3%82%8C%E3%82%92%E5%91%BC%E3%81%B6`) for dividing work between implementation and procedures. Judgment: Check whether `NOT ASSESSED` can be returned under the check results contract (`schemas/judgment.json` and `checks/README.md`). Principle content: Check whether applicability, requirements, exceptions, and blocking conditions can be understood. Fresh session: Check whether reading the repository and execution records answers what the system is, how to run it, how to verify it, and where the work currently stands.
- blocking: A fresh session cannot answer one of the questions, a blocking condition in a referenced principle applies, or a referenced contract is violated.
- Do not report: Items outside this aspect's checks. Findings without a failure scenario.
- Output format: Follow the Judgment JSON Schema supplied in the request (`schemas/judgment.json`) and `schemas/finding.json`, with the judgment rules in `checks/README.md`. Return `NOT ASSESSED` when necessary criteria or required verification are unavailable, and record the verified and unverified scope, method, and environment. Do not return findings without a failure scenario, and do not assign severity. Retain all findings; treat nonblocking findings as reference information without requiring fixes. Compare exemption claims with their grounds, and waive only the requirements covered by the exemption.
