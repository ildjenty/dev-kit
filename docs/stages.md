# ステージの候補

kit は、[ループ計画](loop-plan.md)が選ぶステージと[観点](checks.md)を語彙として持つ。各計画では必要なものだけを使う。

## 0 目的

- **決めること**: 誰の、何のための変更か。利用者の言葉で完了条件を定める。
- **決めずに次のステージへ渡すこと**: 手段全般。
- **元に戻せないもの**: なし
- **成果物**: 目的を示す1段落と完了判定条件。

## 1 スコープ

- **決めること**: 含めるものと含めないもの。外部から見えるもの。
- **決めずに次のステージへ渡すこと**: 内部構造。
- **元に戻せないもの**: スキーマ、識別子、契約の型、外部への公開、データの保持。
- **成果物**: スコープの明示と、不可逆な決定の一覧。

## 2 構造

- **決めること**: モジュール、責務、配置、依存の向き。
- **決めずに次のステージへ渡すこと**: 関数の内部。
- **元に戻せないもの**: 配置（変更が難しい）。
- **成果物**: 構造の記録の新しい版と、生成した図、揃える既存の箇所、不採用とした案と理由、未確認の前提、ロールバック手段。

## 3 契約

- **決めること**: インターフェース、データ形式、失敗の種類。
- **決めずに次のステージへ渡すこと**: 実装方式。
- **元に戻せないもの**: 公開した契約。
- **成果物**: 型のシグネチャ。

## 4 手順

- **決めること**: ステップの分け方と、各ステップの検証方法。
- **決めずに次のステージへ渡すこと**: コード。
- **元に戻せないもの**: なし
- **成果物**: 各ステップを [brief](parts/brief.md) として記述した一覧。

## 5 実装

- **決めること**: コード。
- **決めずに次のステージへ渡すこと**: なし
- **元に戻せないもの**: なし
- **成果物**: 差分。

## 調査

- **決めること**: 何が起きているか、どのように動いているか。既存の同種の処理がどう書かれているかを調べる。
- **決めずに次のステージへ渡すこと**: 修正方法。
- **元に戻せないもの**: なし
- **成果物**: 観測と推論を分けた報告。既存の同種の処理がどう書かれているかを含める。

## 試作

- **決めること**: 未確認の前提を実験で確かめる。成果物は破棄する前提で、本番から隔離する。
- **決めずに次のステージへ渡すこと**: 本番のコード。
- **元に戻せないもの**: なし
- **成果物**: 決定と、破棄する成果物。

## 初期化

- **決めること**: harness を導入し、起動できること、テストが1本通ること、進捗が見えること、次の作業を選べることを整える。
- **決めずに次のステージへ渡すこと**: 実装。
- **元に戻せないもの**: なし
- **成果物**: 動作する環境。
