# 判定処理

- 入力: 合意条件は保存ボタンの文言が「保存」であること。
- 対象: ボタンの実際の表示は「登録」。
- 作成者の説明: 保存ボタンの修正は済んだ。
- 判定処理: 作成者の説明は仮説として扱い、実際の表示と合意条件を独立に照合する。この入力では文言の不一致を理由に FAIL を返す。判断基準が欠ける入力は NOT ASSESSED を返す。
- skill: description と配置・参照先は変更しない。check の必須化の変更はない。
