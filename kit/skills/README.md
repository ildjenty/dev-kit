`devkit/SKILL.md` defines the procedure for starting, advancing, submitting, pausing, and resuming work, presenting questions, and launching assigned judges and planners. It uses Markdown with `name` and `description` in YAML front matter.

`devkit init` installs the canonical skill in `.agents/skills/devkit/` and links `.claude/skills/devkit` to it. Host settings and subagent definitions are in the installed kit copy's `hosts/` directory. Follow the commands and returned instructions described in the skill; there is no separate operations playbook.
